# AUD-V02 Floor Plans · BIMGBPS §5.2.3
关联：[TL-V02](../../../GBP%20Tasks/Views/TL-V02_Floor_Plans.md) · Roadmap 卡片 V02 · MA-4.1、MA-4.6、MA-7.5 · [LIM-03、LIM-30](../../L1-Domain/DK-AUD-002_Limits_Index.md) · [DK-AUD-004 §3](../../L1-Domain/DK-AUD-004_Colour_Standards.md)

## 1. 适用性

每个项目都适用。不适用时：不存在这种情况；每个独特布局的楼层都要有平面。

## 2. 要取得的信息

- 每层平面视图：比例、视图样板、所在图纸。
- 每个视图内按类别计数：轴网、尺寸、剖面 / 立面标记、门、门标记、房间、房间标记、高程点。
- 门标记族显示的是哪个参数（编号还是防火等级）。
- 着色像素取样，与图例视图对照。
- 未放置 / 未闭合房间清单（来自 AUD-A1 MA-4.1）。

## 3. L1 检查项

没有该图时：缺某层平面 → 该层 Missing。

| ID | 条文 | 查什么 | 判 |
| --- | --- | --- | --- |
| V02-L1 | (a) 合规表达 | 走距（DTD）等标示是否在图上 | 有 → 交 L2；无 → Partial |
| V02-L2 | (b) 轴网和柱距 | 各视图轴网数、柱距尺寸 | 某层（常见：机房顶层）无轴网 → 该层 Fail |
| V02-L3 | (c) 剖面、立面标记 | 标记数 | 有 → Pass |
| V02-L4 | (d) 墙厚 | 外墙、内隔墙厚度尺寸 | 只有外墙 → Partial |
| V02-L5 | (e) 用途 / 上层线 / door marks | 房间名与用途；上层建筑线有无注明；门标记数 ÷ 门数 | 只标防火门 → Partial |
| V02-L6 | (f) 房间、走廊、楼梯尺寸 | 房间尺寸、走廊净宽、楼梯宽 | 缺 → Partial |
| V02-L7 | (g) 外伸、幕墙 | 冷气机平台、幕墙尺寸 | 只有文字 → Partial |
| V02-L8 | (h) ADM-9 着色 | GEN-05，对图例 | 一致 → Pass |
| V02-L9 | 高程点格式 | GEN-04 | 非 `X.XXX mPD` → Fail（Minor） |
| V02-L10 | 房间标记 | 房间数 − 房间标记数，对照未放置房间 | 差额无法解释 → Unclear |

## 4. L2 计算与限值

| ID | 计算 | 限值 | 缺什么时 |
| --- | --- | --- | --- |
| V02-C1 | 走距、出口宽度、出口数 | LIM-30（FS Code Part B） | 原文缺 → Unclear（DK-AUD-006 M-01） |

## 5. 常见坑

- 门标记族按 FRR 分类，只给防火门出标记：数量少是族的设计问题，不一定是漏标。
- 机房顶层视图无轴网，只有外框尺寸。
- 内墙厚、走廊净宽常不标。
- 名称带 `_pat` 的图案视图不属 BIMGBPS 要求，不判。

## 6. 外部输入

INP-06（用途、人数）。
