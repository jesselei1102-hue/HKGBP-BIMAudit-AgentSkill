# AUD-V03 Sections · BIMGBPS §5.2.4
关联：[TL-V03](../../../GBP%20Tasks/Views/TL-V03_Sections.md) · Roadmap 卡片 V03 · MA-2.4、MA-2.5 · [LIM-03、LIM-13](../../L1-Domain/DK-AUD-002_Limits_Index.md)

剖面与立面共用 §5.2.4 (a)–(h)。本文件也是 [AUD-V04](AUD-V04_Elevations.md) 的基础。

## 1. 适用性

每个项目都适用。不适用时：不存在这种情况；至少要有纵、横两个剖面，并穿过最高点。

## 2. 要取得的信息

- 每个剖面视图：比例、样板、所在图纸；轴网数、标高数、尺寸数。
- 层高尺寸；标高标头显示的文字。
- **标高基准**（GEN-04）：各 Level 类型、高程点类型的标高基准设置；项目基点与测量点高程；标高名称数字与显示值。
- 各视图有无 mean street level（MSL）/ 街道标高。
- 总高尺寸的起量点（MSL 还是首层）。
- 有无限高线或「NIL」注明。
- ADM-9 着色取样。

## 3. L1 检查项

没有该图时：没有剖面 → Missing；只有一个方向 → Partial。

| ID | 条文 | 查什么 | 判 |
| --- | --- | --- | --- |
| V03-L1 | (a) 轴网与主要尺寸 | 轴网、总尺寸、柱距 | 有 → Pass |
| V03-L2 | (b) 结构层高 | 层高尺寸 | 有 → Pass |
| V03-L3 | (c) 各层 HKPD 标高 | 显示格式（LIM-03）；基准一致（GEN-04） | 非 `X.XXX mPD` → Fail；基准不一致 → Major |
| V03-L4 | (d) 外伸、幕墙尺寸 | 尺寸 | 只有文字 → Partial |
| V03-L5 | (e) 邻街标高 | MSL / 街道标高在哪几个视图 | 只有部分视图有 → Partial |
| V03-L6 | (f) 建筑高度 | 从 MSL 量起的高度尺寸 | 从首层量起或缺 → Partial |
| V03-L7 | (g) 法定图则 / 地契限高 | 限高线或「NIL」 | 都没有 → Fail |
| V03-L8 | (h) ADM-9 着色 | GEN-05 | 一致 → Pass；个别材质颜色不符 → Minor |

## 4. L2 计算与限值

| ID | 计算 | 限值 | 缺什么时 |
| --- | --- | --- | --- |
| V03-C1 | 建筑高度（LIM-13）：最低指明街道平均水平 → 最高实用楼面之上屋顶平均高度 | OZP / 地契限高 | 有两个合理口径（到主屋面 / 到机房顶）时两个都算（INP-11）；限高 INP-04 缺 → Unclear |

## 5. 常见坑

- 标高标头族把「m」写死在标签里，改类型参数改不掉。
- 标高基准是项目基点而项目基点高程 ≠ 0 → 显示值整体偏移（第 1 轮：0.100 m）。
- 图上两处写的建筑高度不一致（第 1 轮：一处到主屋面、一处到机房顶）。
- 屋顶围栏材质颜色与 ADM-9 不符。
