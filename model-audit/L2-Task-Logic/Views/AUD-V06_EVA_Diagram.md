# AUD-V06 EVA Diagram · BIMGBPS §5.2.6
关联：[TL-V06](../../../GBP%20Tasks/Views/TL-V06_EVA_Diagram.md) · Roadmap 卡片 V06 · [LIM-26、LIM-31](../../L1-Domain/DK-AUD-002_Limits_Index.md)

## 1. 适用性

所有须设紧急车辆通道的建筑物（Cap. 123F reg 41D；PNAP APP-136）。不适用时：只有 BA 按 reg 41D 豁免的情况，理由句须引豁免依据，交 AP。

## 2. 要取得的信息

- EVA 图视图（每层或每个体量）、所在图纸、图例视图。
- EVA 面积方案里各 Area 的周长（= 建筑周界）、面积。
- 被 EVA 服务的立面：用几何边长加总（不只读参数）。
- 每个塔楼、楼梯屋分开取。
- APP-136 第 4 段 (a)–(g) 各项在图上的表达：EVA 着色、阔度、内外转弯半径、承重、坡度、标志与防撞闸、上盖结构净高剖面、主要立面着色、长度与百分比计算、铺面。
- 对应计算表的形式（GEN-01）。

## 3. L1 检查项

没有该图时：适用而无 EVA 图 → Missing。

| ID | 条文 | 查什么 | 判 |
| --- | --- | --- | --- |
| V06-L1 | (a) 合规表达 | 周界、主要立面长度标示 | 有 → 交 L2 |
| V06-L2 | (b) 主要尺寸 | 周界、服务立面、EVA 阔度与长度 | 有 → Pass |
| V06-L3 | (c) EVA 与主要立面分界 | 着色、标签 | 有 → Pass |
| V06-L4 | (d) 对应表和计算 | GEN-01、GEN-02 | 图片 → Fail；服务立面是手填参数 → 指出 |
| V06-L5 | APP-136 ¶4 (a)–(g) | 逐项 | 缺坡度 / 铺面 → Partial |

## 4. L2 计算与限值

| ID | 计算 | 限值 | 缺什么时 |
| --- | --- | --- | --- |
| V06-C1 | 服务立面 ÷ 周界，每层 / 每体量分别算 | ≥ 25 %（LIM-26） | — |
| V06-C2 | 阔度、净高、承重、坡度、与立面距离 | LIM-31（FS Code Part D） | 原文缺 → 结论写「附条件」或 Unclear |

V06-C1 过而 V06-C2 未能核 → **Pass（附条件）**。

## 5. 常见坑

- 「SERVED FACADE」之类参数是手填值（GEN-02）：数值即使对，也要指出。
- 坡度、铺面常漏注。
- 公共街道可作 EVA（APP-136 第 5 段），服务立面可以计入面向街道的边。

## 6. 外部输入

无（FS Code 属 L1，见 DK-AUD-006 M-03）。
