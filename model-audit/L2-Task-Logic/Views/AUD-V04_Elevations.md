# AUD-V04 Elevations · BIMGBPS §5.2.4
关联：[TL-V04](../../../GBP%20Tasks/Views/TL-V04_Elevations.md) · Roadmap 卡片 V04 · MA-2.4、MA-2.5 · [LIM-03、LIM-13](../../L1-Domain/DK-AUD-002_Limits_Index.md)

同 [AUD-V03](AUD-V03_Sections.md)（同一张条文清单 §5.2.4 (a)–(h)、同一组检查与限值）。本文件只写差异。

## 1. 适用性

每个项目都适用，四个方向的立面都要有。不适用时：不存在这种情况。

## 2. 要取得的信息

同 AUD-V03 §2，对象换成立面视图。另取：每个方向立面是否存在；窗 / 开口的标记与尺寸。

## 3. L1 检查项

没有该图时：缺某方向立面 → 该方向 Missing。

检查项 V04-L1 至 V04-L8 与 V03-L1 至 V03-L8 一一对应。差异：

| ID | 条文 | 差异 |
| --- | --- | --- |
| V04-L4 | (d) 外伸、幕墙尺寸 | 立面上还要看窗宽高、窗台高度；只有标记无尺寸 → Partial |
| V04-L5 | (e) 邻街标高 | 立面常缺街道标高 → Partial |
| V04-L8 | (h) ADM-9 着色 | 立面材料多（批荡、玻璃、金属），逐色对图例 |

## 4. L2 计算与限值

同 V03-C1（建筑高度与限高）。立面不另算。

## 5. 常见坑

- 只实看部分立面、其余只看计数：要在报告里写明哪些只核了计数。
- 屋顶金属围栏画成石材灰。
