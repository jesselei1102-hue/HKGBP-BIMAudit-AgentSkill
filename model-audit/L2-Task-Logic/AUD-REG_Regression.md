# AUD-REG · 回归

Layer 2，与软件无关。模型改过之后（功能 B 写入，或人在 Revit 里改），重跑功能 A 的相关部分，把上一轮的每个发现标成：**已关 / 部分关 / 未关 / 不适用（AP 决定后）**，另记新问题。只读。

## 1. 前提

1. 确认打开的是要回归的那个文件（副本，不是原档），记下路径。
2. 确认文件已存档。读到的是「会话状态」还是「已存文件」，在报告里写清楚。
3. 读基线：
   - 上一轮 Audit Report 的 Findings 和各 Task 结论。
   - 上一轮之后的修改记录（每次写入的对象、动作、还要人工的事）。
4. 为这个模型做一份回归清单（基线数字、逐个 F 编号、要重判的 Task）。没有就先做，交给人看过再跑。

## 2. 步骤

1. **基线数字先复核**。选 5–10 个必须不变的数：地盘面积、有盖面积、总 GFA、各豁免合计、申报 GFA、分区面积、绿化面积、视图数、图纸数。有变化先停，查清楚再继续。
2. **逐个 F 编号回查**，按下表。
3. **查副作用**。对每一次修改：受影响视图的元素数、导出图像上的新重叠 / 缺标签 / 变色、连带删除的元素。
4. **重判受影响的 Task**：
   - 修改动过的 → 按对应 AUD 重判 L1。
   - 上一轮因缺原文 / 资料而 Unclear、现在已有的 → 补判 L2。
5. **新问题**接着编新 F 编号，不改旧编号的意思。
6. **报告**：加「第 N 轮回归」一节。旧结论不删，用「→」标注变化，附证据。

## 3. 问题类与关闭标准

| 问题类 | 查什么 | 关闭标准 |
| --- | --- | --- |
| 计算表是图片（GEN-01） | 有没有对应的模型明细表；是否放在图纸上；图纸上的图片是否已删；导出图纸图像实看；明细表数据与基线逐行对 | 图片被明细表取代，数字一致 |
| 表里是手填数（GEN-02） | 字段是否改为软件量得 / 计算值 | 值随几何变化；无法确认时为「部分关」 |
| 未放置 / 未闭合 Room、Area（MA-4.1、4.3） | 面积 0 的数量 | 0 个，且总面积不变 |
| 边界可疑的面积 | 该元素面积；所在视图图像 | 面积合理，或有人说明 |
| 未用类型 / 残留数据（MA-3.4） | 实例为 0 的类型数 | 0 个 |
| 项目信息 / 图框占位（MA-7.1） | 项目信息、图框参数 | 无矛盾、无占位值 |
| 名称错字 / 默认名 | Area / Room 名称 | 0 个 |
| 无半色调底图（GEN-03） | 面积图图像的灰阶占比，与基线截图比 | 墙线变灰、灰阶占比明显上升 |
| 缺项且无 N/A | 图纸上的 N/A 表 / 注释；每个 N/A 理由句 | 每个缺项不是补齐，就是有理由 |
| 重复面积 | 同层同名同面积的 Area 组数 | 每层一套 |
| 标高格式（GEN-04） | 导出平面 / 剖面图像上的文字；类型设置 | 显示 `X.XXX mPD`，无重叠 |
| 标高基准（GEN-04） | 标高基准设置；项目基点 / 测量点高程 | 与 AP 决定一致；未决定 → 维持 Unclear |

## 4. 规则

- 回归只读。发现要修的，记下交功能 B，不在回归里顺手改。
- 「说已改」不等于已关，要有查询结果或截图证据。
- AP 未决定的项维持原状态；AP 决定后，先记入项目输入清单（[AUD-000](AUD-000_Audit_Flow.md) INP-11 至 INP-17），再改状态。
- 数字与基线不同：先怀疑「读的是不是同一个文件 / 会话」，再怀疑模型。
