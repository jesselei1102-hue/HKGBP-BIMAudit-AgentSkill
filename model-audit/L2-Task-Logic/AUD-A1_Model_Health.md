# AUD-A1 · 模型健康（MA-1 至 MA-7）

Layer 2，与软件无关。与具体 Task 无关的模型级检查，编号沿用 Roadmap §05「Model Audit 检查清单」。

- 「盲点」一栏指向 L4 [CAP-gaps](../L4-Capabilities/CAP-gaps.md)：工具读不到时，按该缺口的人工补法做，或记 Unclear。
- 严重度：B = Blocker，M = Major，N = Minor（沿用 Roadmap）。

另查（第 1 轮常见）：

- 同层、同名、同面积的两套 Area → 歧义，记 Minor，并在 V10 / S08 复核前先确认用哪套。
- **面积明显不合理**的 Room / Area（例：楼梯间面积接近整层面积）→ 多半是漏了边界，记 Unclear（Minor），附所在视图截图，交人工看边界。
