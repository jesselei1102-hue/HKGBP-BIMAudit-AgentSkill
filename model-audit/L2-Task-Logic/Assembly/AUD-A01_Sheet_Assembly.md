# AUD-A01 Sheet Assembly · BIMGBPS §4.3(f)、§5.5.1–5.5.2、§6.3–6.4
关联：[TL-A01](../../../GBP%20Tasks/Assembly/TL-A01_Sheet_Assembly.md) · Roadmap 卡片 A01 · MA-7.1 至 MA-7.4 · [DK-AUD-001 G9](../../L1-Domain/DK-AUD-001_Hard_Requirements.md)

## 1. 适用性

每个项目都适用。不适用时：不存在这种情况。

## 2. 要取得的信息

- 图纸数、图框实例数。
- 每张图框的参数：图号、修订、项目名、图名、日期、绘图人。
- 项目信息（项目名、地址、机构、楼宇名称）。
- 图例、缩写、FS 注释视图所在的图纸。
- BIM 文件编号四字段；文件实际的 Revit 版本。

## 3. L1 检查项

没有该图时：有图纸缺图框 → 该图 Fail。

| ID | 条文 | 查什么 | 判 |
| --- | --- | --- | --- |
| A01-L1 | §4.3(f) 每张图有图框 | 图纸数 = 图框实例数 | 不等 → Fail |
| A01-L2 | §5.5.1 图号、修订、项目名、图名 | 必填项已填 | 缺 → Fail |
| A01-L3 | §6.4 图号规则 | A### / C### + 修订字母 + 图名 | 不合 → Minor |
| A01-L4 | §5.5.2 图例、缩写、FS 注释 | 存在 | 缺 → Fail |
| A01-L5 | §6.3 BIM 文件编号 | 软件版本段与文件一致；首次提交 BD 编号留空（注 1） | 不一致 → Minor |
| A01-L6 | 占位内容 | 日期、绘图人、修订日期是否为占位值；项目名与地址是否矛盾 | 有占位 / 矛盾 → Minor |

## 4. L2 计算与限值

无 L2。

## 5. 常见坑

- 项目信息里项目名与地址互相矛盾。
- BIM 编号的软件版本段与文件版本不符。
- 「XX-XX-2018」「Author」「DATE 1」一类占位值。

## 6. 外部输入

INP-09、INP-15。

前置：全部 Views、Schedules（图上内容）；后续：AUD-A04。

无。
