# AUD-A03 Export · BIMGBPS §4、§6
关联：[TL-A03](../../../GBP%20Tasks/Assembly/TL-A03_Export.md) · Roadmap 卡片 A03 · MA-1.1 至 MA-1.6 · [LIM-04、LIM-05](../../L1-Domain/DK-AUD-002_Limits_Index.md)

## 1. 适用性

每个项目都适用。不适用时：不存在这种情况；单一文件、无链接时，链接层级说明文本 → N/A。

## 2. 要取得的信息

- 文件格式、大小、Revit 版本、链接与导入（同 AUD-A1 MA-1）。
- 试导一张图纸的 PDF：页面尺寸，与图框尺寸比。
- 同目录有无其他版本的文件（例：不同 Revit 版本另存的副本）。
- 图纸是否由模型直接生成（GEN-01 汇总）。

## 5. 常见坑

- 检查用的 PDF 导出可能固定为某一纸张尺寸；正式出图要用 Revit 的打印设置。
- 同目录有另一版本的副本：问清楚交哪个（INP-15）。
